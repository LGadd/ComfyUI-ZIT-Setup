Free AI images on your own GPU

Z-Image Turbo + ComfyUI. No subscription, no credits, no queue. About 20 minutes to set up, most of it waiting for downloads.

Z-Image Turbo · 6B · Apache 2.0 Commercial use OK NVIDIA 8–16 GB 3.4 s / image on an RTX 5070 Ti

1Check your graphics card

You need an NVIDIA card. Find its VRAM: on Windows, open Task Manager → Performance → GPU and read “Dedicated GPU memory”. On Linux, run nvidia-smi.

Your VRAM decides which model file you download in step 3:

2Install ComfyUI

Windows or Mac (easiest)

  1. Download ComfyUI Desktop: comfy.org/download
  2. Run the installer, pick NVIDIA as the GPU, and accept the default folders.
  3. When it opens, you’re done. Note the install folder it showed you. That’s your ComfyUI folder below.

Linux

git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI
python -m venv venv && source venv/bin/activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128

Then open http://127.0.0.1:8188 in your browser.

Already have ComfyUI? Update it first. Z-Image Turbo needs a recent version (Desktop: it updates itself; manual install: git pull).

3Download three files

A model, a text encoder and a VAE. Put each one in its own folder inside ComfyUI/models/.

① The model → models/diffusion_models/

Pick one, based on your VRAM from step 1:

16 GB: BF16 (12.3 GB) 12 GB: FP8 (6.2 GB) ≤8 GB: GGUF Q4_K_M (5.0 GB)

GGUF users: .gguf files go in models/unet/ instead, and need one extra step (see “Using GGUF” below).

② The text encoder → models/text_encoders/

qwen_3_4b.safetensors

4Load the workflow

  1. Restart ComfyUI so it sees the new files.
  2. Open Workflow → Browse Templates and search Z-Image Turbo.
    Not there? Download image_z_image_turbo.json and drag it onto the ComfyUI window.
  3. Check each loader box shows your file name. If you used FP8, click the model box and pick the FP8 file.
  4. Type a prompt and press Run. Your image appears on the right and is saved in ComfyUI/output/.

Keep CFG at 1. It’s a turbo model. Push CFG higher and images come out burnt and oversaturated. More steps doesn’t help much either; 8–9 is the sweet spot.

+Using GGUF (8 GB cards)

  1. Open Manager → Custom Nodes Manager, search ComfyUI-GGUF (by city96), install it and restart.
  2. Put the .gguf file in models/unet/.
  3. In the workflow, double-click empty canvas, add Unet Loader (GGUF), pick your file, and connect its output where the old model loader’s output went. Delete the old loader.

Got a bit more room? Q5_K_M (5.6 GB) looks slightly better than Q4_K_M.

?If something goes wrong

Red box / “value not in list”: a file is in the wrong folder or ComfyUI wasn’t restarted. Re-check step 3, then restart.
Out of memory (OOM): use the smaller model for your card from step 1, and close games or other GPU-heavy apps.
Template missing / unknown node: ComfyUI is too old. Update it.
Images look burnt or neon: CFG is above 1. Set it back to 1.0.
First image is slow? Normal. The first run loads the models into memory. After that, each image takes seconds.
