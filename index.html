01

Check your graphics card

~1 min

You need an NVIDIA card (GTX 20 series or newer). Find out how much VRAM it has:

Press Ctrl + Shift + Esc → Performance → GPU. Read Dedicated GPU memory.

nvidia-smi --query-gpu=name,memory.total --format=csv

Pick your card below. The rest of the page will show the right download for it.

02

Install ComfyUI

~5 min

We'll use the official portable build. It has Python built in, so there's nothing else to install, and the folders are always in the same place.

  1. Download it: ComfyUI_windows_portable_nvidia.7z 2.0 GB
  2. Right-click the file → Extract All into C:\. On Windows 10, use 7-Zip.
    You now have C:\ComfyUI_windows_portable\.
  3. Double-click run_nvidia_gpu.bat in that folder. A black window opens and ComfyUI opens in your browser.
NOTEWon't start? Update your NVIDIA driver from the NVIDIA App first. If Windows blocks the file, right-click it → Properties → tick Unblock.

You need git, Python 3.12 or 3.13, and a working NVIDIA driver (nvidia-smi runs).

git clone https://github.com/Comfy-Org/ComfyUI ~/ComfyUI
cd ~/ComfyUI
python -m venv venv
source venv/bin/activate
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt

Start it, then open 127.0.0.1:8188:

cd ~/ComfyUI && source venv/bin/activate && python main.py
FISHUsing fish shell? Use source venv/bin/activate.fish and replace && with ; and.
NOTEAlready have ComfyUI? Update it first with cd ~/ComfyUI && git pull && pip install -r requirements.txt. Z-Image Turbo needs a recent version.

GGUF only: add the GGUF loader

ComfyUI can't read .gguf files on its own. Install the ComfyUI-GGUF node:

  1. Download ComfyUI-GGUF (zip) and extract it into C:\ComfyUI_windows_portable\ComfyUI\custom_nodes\.
  2. In C:\ComfyUI_windows_portable\, click the address bar, type powershell and press Enter. Then run:
.\python_embeded\python.exe -m pip install -r .\ComfyUI\custom_nodes\ComfyUI-GGUF-main\requirements.txt
cd ~/ComfyUI/custom_nodes
git clone https://github.com/city96/ComfyUI-GGUF
source ../venv/bin/activate
pip install -r ComfyUI-GGUF/requirements.txt
04

Load the workflow

~2 min
  1. Click on the ComfyUI page and press R so it sees the new files.
  2. GGUF only: restart ComfyUI once so the new GGUF node loads: close the black window, then run run_nvidia_gpu.bat again.Ctrl + C in the terminal, then start it again.
  3. Open Workflow → Browse Templates and search Z-Image Turbo.
    Not listed? Download image_z_image_turbo.json and drag it onto the ComfyUI page.
  4. Click the model loader box and pick z_image_turbo_fp8_e4m3fn.safetensors.
  5. Double-click empty space, search Unet Loader (GGUF) and add it. Pick your .gguf file, drag its MODEL output to where the old model loader was connected, then delete the old loader.
  6. Type your prompt in the text box and press Run.
DONEYour image appears on the right and is saved in ComfyUI\output\~/ComfyUI/output/. The first one is slow while the models load. After that, each image takes seconds.

If something goes wrong

ERRRed box on a node / "value not in list"
FIXA file is in the wrong folder, or ComfyUI hasn't refreshed. Check step 03, then press R on the ComfyUI page.
ERRCUDA out of memory
FIXPick the next tier down in step 01 and download that model. Close games and other GPU-heavy apps.
ERRMissing node type / template not found
FIXComfyUI is too old. Run update\update_comfyui.bat in the portable folder. Run git pull in ~/ComfyUI.
ERRImages look burnt, neon or deep-fried
FIXCFG is above 1. Set it back to 1.0.
ERRpip can't find torch / "Torch not compiled with CUDA"
FIXYour Python is too new, or torch came from the wrong index. Make the venv with Python 3.12 or 3.13 and re-run the torch line from step 02.
ERRBlack window closes straight away
FIXUpdate your NVIDIA driver, then run run_nvidia_gpu.bat again. To read the error, open PowerShell in the folder and run .\run_nvidia_gpu.bat.
